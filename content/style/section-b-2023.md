# Style patterns, June 2023 papers (2023-06-25-s1-en, 2023-06-24-s3-en)

Section B (90 discipline questions + 10 Teaching Methodology per paper). Paraphrased patterns only.

- Section B stems and options are image-embedded; discipline questions appear mixed across topics, not grouped by subject.
- Direct recall dominates (about 80% in s1, 55-60% in s3); mostly one-line ("which of the following is ..."), often with short one- to three-word options.
- Fill-in-the-blank stems with a single blank are common (about 15%), frequently with paired blanks whose options are paired terms.
- "Which of the following is NOT / FALSE ..." negation stems are frequent (about 15-20%), especially for OS, Linux, SE, XML parsers, and network statements.
- Two-statement (i)/(ii) formats with "only (i) / both / neither" options appear a few times in the discipline part (servlets, queues, TCP/P2P-type topics).
- Match-the-following is rare in discipline (one unit-matching item in s1, none in s3's discipline part).
- Code-output items are few (2-3 per paper): short Java/C snippets testing quirks (octal literal, pointer arithmetic, identifiers named like class names).
- Numeric items are 3% (s1) to 18% (s3) and are mostly single-formula: mensuration, probability, binary conversion, subnet host counts, cache tag bits, spring/LED physics, counter timing, interpolation.
- Hard questions cluster in numerics and DBMS/DAA/COA theory: cache tag size, conflict serializability, subset-sum, ripple counter delay, Lagrange interpolation, central-difference operators.
- Only one figure-based question per paper (flowchart symbols in s1, graph articulation points in s3).
- Breadth is very wide: about 30 syllabus topics each get 1-5 questions, and almost no topic gets more than 6.
- Heaviest recurring areas: networks/TCP, Java/.NET/C/C++ language facts, XML/DTD/CSS/web front end, SE models, knowledge management, MIS, Linux commands.
- Light-weight business subjects (economics, accounts, business organisation, e-commerce) appear as very easy definitions, usually one to three per paper each.
- Math/stats/numerical items are typically textbook formula applications, not multi-step derivations.
- Front-end tooling questions (frameworks, CSS preprocessors, directives) show modern web terms beyond the printed syllabus (AngularJS, jQuery, Sass).
- Distractors are usually plausible same-category terms (other testing types, other topologies, other normal forms of the same family).
- Difficulty differs by sitting: s1 is about 70% easy / 30% medium with no hard items; s3 is about 35% easy / 55% medium / 10% hard, with many more numeric and statement items.
- Teaching Methodology is almost entirely text, 4 options, many with I/II statement formats (about half the items).
- Methodology content: Piaget/child development, parenting and brain-language areas, learning styles, reinforcement, inclusive provisions, project/heuristic methods.
- Methodology also includes occasional trivia items (a freedom-era newspaper or reformer) that look unrelated to pedagogy.
- Methodology options in statement items use the fixed set "only I / only II / both / neither", with the order shuffled between items.
- Methodology questions are mostly conceptual, one-sentence stems, and are rarely numeric or match-type (one parenting match item in s3).
